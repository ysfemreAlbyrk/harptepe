# Moderatör El Kitabı

Moderatör oyunun hakemi, kayıt memuru ve tempo bekçisidir. Dijital sistem hesaplamada yardımcı olur ama masadaki adalet ve akış moderatöre aittir.

## Dosyalar

- [Tur yönetimi](tur-yonetimi.md)
- [Skor ve cezalar](skor-ve-cezalar.md)

## Temel ilkeler

1. **Önce adalet, sonra hız.** Kayıt hatası olursa durdurup düzelt.
2. **Tescilsiz büyük işlem yok.** Oyuncular isterse sözlü konuşsun ama bağlayıcı sonuç ancak tescille doğar.
3. **Dijital ekran gerçeğin kaydıdır.** Kart fiilen el değiştirmediyse sisteme işleme.
4. **Kuralları oyuncu yerine hatırla ama oyuncu yerine oynama.**

## Oyun öncesi kontrol listesi

- Kaynak kartları ve altın kartları hazır
- Rol kartları veya rol listeleri hazır
- Sandıklar numaralı ve görevleri yerleştirilmiş
- Mühür/etiketler dağıtılmış
- Anlaşma formları Tescil Masası'nda
- Web uygulaması açık
- Projeksiyon ekranı hazır
- Oyuncu giriş bağlantısı test edilmiş
- Senkronizasyon durumu “bağlı” görünüyor

## Sık kararlar

- Küçük takaslar tescil gerektirmez.
- Borç, vadeli ticaret, ittifak, saldırmazlık ve Ortak Anıt tescillenmelidir.
- Kural ihlalinde önce uyarı, tekrarında PP cezası uygundur.
- Oyuncular arasındaki sözlü anlaşmazlıkta moderatör olguya bakar; kim daha yüksek sesle konuşuyorsa ona değil.
